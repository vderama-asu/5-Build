Converted the Indie Film Collective website from a single-page layout into a responsive multipage website. Created additional pages for Screenings, Workshops and Collaborations with dedicated content and consistent nav.

Updated the CSS to use a mobile-first approach, adding a media query for screens 800px and wider. Layout uses a two-column CSS grid for the main content. Flexbox is implemented to arrange links and cards horizontally with card withs set to 30% width.

The written content for this website were generated with the assistance of ChatGPT and were reviewed and edited by the student. All HTML and CSS were written by the student.
